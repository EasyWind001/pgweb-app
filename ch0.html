中国公共管理的认知框架

    序

    先建立你的「治理坐标系」

    在谈任何制度之前，先谈一个更根本的问题：为什么你在生意场上游刃有余，进了体制内的话题却像到了另一个世界。

    0.1 为什么懂商业、懂外贸，却对体制内陌生

    你做外贸 2B，脑子里有一套非常成熟的算法：客户是谁、需求是什么、报价怎么算、账期怎么谈、风险怎么控。这套算法之所以好用，是因为它建立在一条清晰的因果链上——用钱来衡量得失，用合同来锁定关系，用效率来评价好坏。你只需要对结果负责，不需要对「过程是否合规」负责。

    但体制内的算法不一样。它不首先问「这件事划算不划算」，而是先问三件事：这事归谁管？流程走到哪一步了？出了问题谁负责？你会觉得它「慢」「绕」「讲形式」，其实是因为它的底层目标不是利润最大化，而是秩序与稳定。一个政府一年经手的钱可能不如一个大企业多，但它要面对的是几百万人的诉求、几十个上级部门的要求，以及「不能出错」的政治责任。

    这就是你感到陌生的根源：不是你不聪明，而是你的默认坐标系是「市场」，而体制内运行的是「权力—责任」坐标系。本书要做的第一件事，就是帮你把坐标系换过来。换过来之后，你会发现很多以前看不懂的东西，突然都说得通了。

    0.2 你的三个盲区

    把你感到陌生的东西归纳一下，其实就三块，正好对应本书的前几卷：

    • 历史盲区——你不知道今天的制度为什么长成这样，于是你看每一个机构都觉得「凭空冒出来」。其实人大、政府、纪委监委、条条块块，都能在两千年的中央集权史里找到影子。这对应第一卷「历史的基因」。
    • 体制盲区——你知道有省委、市委、县委，但说不清它们之间怎么指挥、怎么分工、谁大谁小。这对应第二卷「当代的骨架」。
    • 方法盲区——你知道要「为人民服务」，但一落到申论对策，就只会写「加强领导、提高认识」。这对应第四、五、六卷，教你政策怎么运转、议题怎么分析、考场怎么表达。

    还有一个隐藏的盲区你可能没意识到：你只熟悉中国的样子，却说不清它和国外有什么不一样。而「没有对比，就没有理解」——所以本书专门用第三卷「比较的视角」来讲国外政治体系，帮你用「他者的镜子」照见中国体制的特点。

    0.3 本书怎么读、怎么用

    全书六卷，是一条「历史 → 体制 → 对比 → 技艺 → 现场 → 考场」的递进线。前三卷是打地基，让你「看懂」；中间两卷是学方法，让你「会分析」；最后一卷是上考场，把前面积累的认知转化成得分。

    给你三个阅读建议：第一，不要跳读前三卷。很多人申论写不好，不是文笔差，是地基空。第二，每一章末尾的「申论·应用」「面试·应用」框一定要看，那是把知识接到考场的接口。第三，遇到案例，别急着往下翻，停下来想一想：如果换成我，会怎么处理？

    0.4 一个贯穿全书的案例：一份文件从中央到村口

    先给你一个「总览镜头」，后面每一卷都会回来看它。假设国家决定要治理农村乱占耕地建房，这个决定最终落到一个村的支书身上，中间至少要经过这样一条链：

    案例 · 一份文件的旅程

    中央发文件 → 省里部署 → 市里动员 → 县里分解 → 乡镇落实 → 村里动手

    中央层面，国务院或主管部门（这里是自然资源部、农业农村部）联合发文，提出总要求和时间表；省里接文后，召开专题会，把任务分给各厅局，并加上本省的「加码」要求；市里再往下压，明确「谁的地盘谁负责」；到了县里，开始拆解成具体数字——要排查多少户、拆多少宗、什么时候销号；乡镇是真正的执行层，干部要一户一户去核实、动员；村支书则在最末端，负责把政策变成村民能听懂的话、能接受的做法。

    这条链，就是本书第二卷要讲的「纵向治理」，第四卷要讲的「政策执行」。请记住这个例子，它会在后面反复出现。当你有一天坐在考场上，看到任何关于「政策落实」「基层治理」的材料，都能自动把它接回到这条链上。

    本章小结
    • 你的陌生感来自坐标系差异：市场思维对结果负责，体制思维对过程与责任负责。
    • 三个盲区：历史、体制、方法，外加一个隐藏盲区——缺乏中外对比。
    • 六卷主线：历史 → 体制 → 对比 → 技艺 → 现场 → 考场。
    • 记住「中央—省—市—县—乡—村」这条纵向链条，它是理解一切的入口。
